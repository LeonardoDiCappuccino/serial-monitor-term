# Serial Monitor Terminal

A simple serial port monitor for VS Code running in terminal

## How to use it

1. Open the command palette (`Ctrl+Shift+P` or `Cmd+Shift+P` on Mac)
2. Type "Open Serial Monitor" and hit enter
3. Pick your serial port from the list
4. Choose your baud rate
5. Start chatting with your device!

## Features

- Choose from any available serial port on your system
- Common baud rates supported (9600, 19200, 38400, 57600, 115200, and more)
- Send and receive data in a familiar terminal interface
- Multiple monitors can run at the same time
- ANSI Escape Codes compatible
